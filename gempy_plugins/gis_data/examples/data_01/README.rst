Data source
-----------

``interfaces.*``, ``topo.*``, and ``strike_lines.*`` (originally ``interfaces1_lines.*``,
``topo1.*``, and ``strike_lines1.*``) are vendored from `cgre-aachen/gemgis_data
<https://github.com/cgre-aachen/gemgis_data/tree/main/data/example01_planar_dipping_layers>`_
(CC BY 4.0), part of the "Example 1 -- Planar Dipping Layers" tutorial dataset. Used
by ``example01.py``.
