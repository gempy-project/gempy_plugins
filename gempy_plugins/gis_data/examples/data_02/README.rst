Data source
-----------

``interfaces.*``, ``topo.*``, and ``strikes.*`` (originally ``interfaces16.*``,
``topo16.*``, and ``strikes16.*``) are vendored from `cgre-aachen/gemgis_data
<https://github.com/cgre-aachen/gemgis_data/tree/main/data/example16_all_features>`_
(CC BY 4.0), part of the "Example 2 -- Unconformable Faulted Layers" tutorial dataset
(`notebook
<https://github.com/cgre-aachen/gemgis_data/blob/main/notebooks/06_combined_models/example02_unconformable_faulted_layers.ipynb>`_).
Used by ``example02.py``.
