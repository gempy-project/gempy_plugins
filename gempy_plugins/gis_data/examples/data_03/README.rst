Data source
-----------

``interfaces.*``, ``topo.*``, and ``strikes.*`` (originally ``interfaces9_rotated.*``,
``topo9_rotated.*``, and ``strikes9_rotated.*``) are derived from `cgre-aachen/gemgis_data
<https://github.com/cgre-aachen/gemgis_data/tree/main/data/example09_faulted_layers>`_
(CC BY 4.0), part of the "Faulted Layers" tutorial dataset (`notebook
<https://github.com/cgre-aachen/gemgis_data/blob/main/notebooks/04_faulted_layers/example02_faulted_layers.ipynb>`_)
-- rotated 35 degrees about the data's shared centroid so the layers are no longer
axis-aligned, for ``example03.py`` to demonstrate re-aligning and cropping them.
